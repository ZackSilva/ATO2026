# Space Dodger

A small, single-player browser game built during the vibe coding workshop.

## Play locally

Open `index.html` in Safari, Chrome, or another modern browser. No installation or server is needed. On a Mac, you can open the folder in Finder and double-click `index.html`.

Choose **Start flight**, then press **Space** or tap/click **Boost** to rise. Fly through each gap for one point. Touching a barrier or the top or bottom edge ends the round. Choose **Play again** to start fresh.

**Pause / Help** pauses the flight. Leaving the window also pauses it; choose **Resume flight** when you return. Holding Space does not repeat boosts.
